# Cobblemon Better Badges

## Introduction

This mod introduces a new take on the badge system for the mod Cobblemon,
this mod is mainly built for modpack creators that has a gym or league system.

## The Leagues!
The mod introduces a way to implement custom leagues 
such as the Indigo League in kanto

## Upcoming Features

- ### Data Driven Customization
  + Custom badges
  + Custom badge cases
- ### RTC Trainers Integration
  + A new process of giving badges to the players
- ### BADGE BOOSTS
  + Badges will provide outside of battle boosts such as vanilla boosts or cobblemon related boosts
- ### Trophy System
  + The trophy system will be the way to activate badge boosts
